Method

Score = 20 × (0.30 × severity + 0.20 × frequency + 0.20 × market + 0.15 × willingness to pay + 0.15 × competition gap). Each factor is scored 1–5 by the AI with a reason; Python calculates the total, so the range is 20–100. The weights are initial assumptions from the MVP plan, not research findings.

A problem is kept only if at least 2 independent sources contain a verified quote. Pages from the same website count once (separate forum threads count separately), and near-copies of the same text count once.
